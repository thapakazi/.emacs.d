* Core Philosophy
This config follows: *Capture Fast → Review Weekly → Do Daily → Complete*

* 6. Better Agenda Display
#+begin_src emacs-lisp
  ;; Cleaner agenda look
  (setq org-agenda-block-separator ?─)
  (setq org-agenda-current-time-string "◀── NOW ──────────────────")
  (setq org-agenda-time-grid
        '((daily today require-timed)
          (800 1000 1200 1400 1600 1800 2000)
          " ┄┄┄┄┄ " "┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄"))

  ;; Deadline/scheduled display
  (setq org-deadline-warning-days 7)
  (setq org-agenda-skip-deadline-prewarning-if-scheduled t)

  ;; === CLEAN TAG & TEXT DISPLAY ===
  ;; Prefix format - clean and compact
  (setq org-agenda-prefix-format
        '((agenda . " %i %-10:c%?-10t% s")
          (todo   . " %i %-10:c ")
          (tags   . " %i %-10:c ")
          (search . " %i %-10:c ")))

  ;; Start week on Monday
  (setq org-agenda-start-on-weekday 1)

  ;; Compact view
  (setq org-agenda-compact-blocks t)

  ;; Truncate lines - no wrapping
  (add-hook 'org-agenda-mode-hook
            (lambda () (setq truncate-lines t)))

  ;; === FLUID TAG DISPLAY ===
  ;; Dynamically set tag column based on window width
  (defun my/org-agenda-set-tags-column ()
    "Set tags column to align near right edge of window."
    (setq org-agenda-tags-column (- 2 (window-width))))

  ;; Truncate long tags with ellipsis (only tags, not text)
  (defun my/org-agenda-truncate-tags ()
    "Truncate tags longer than 20 chars with ellipsis."
    (let ((inhibit-read-only t)
          (max-tag-width 20))
      (save-excursion
        (goto-char (point-min))
        (while (re-search-forward "[ \t]+\\(:[^ \t\n]+:\\)[ \t]*$" nil t)
          (let* ((tag-str (match-string 1))
                 (tag-len (length tag-str)))
            (when (> tag-len max-tag-width)
              (replace-match
               (concat "  " (substring tag-str 0 (- max-tag-width 2)) "..")
               t t)))))))

  ;; Apply on agenda render
  (add-hook 'org-agenda-finalize-hook #'my/org-agenda-set-tags-column)
  (add-hook 'org-agenda-finalize-hook #'my/org-agenda-truncate-tags t)
#+end_src

* Cheatsheet                                                       :noexport:

** Quick Start: Press ~C-c o~ for everything

#+begin_example
╭─────────────────── Org Workflow ────────────────────╮
│                                                     │
│  Capture          View            Do                │
│  d: dump task     t: today        x: done           │
│  s: scheduled     w: week         /: search         │
│  D: with deadline i: inbox        r: refile         │
│                   u: upcoming                       │
│                   a: all tasks                      │
│                   c: calendar                       │
│                                                     │
╰─────────────────────────────────────────────────────╯
#+end_example

** Daily Workflow

*** Morning (2 min)
1. ~C-c o t~ → See today's tasks
2. Pick one task, press ~t~ to mark as DOING

*** Throughout Day
- New thought? ~C-c o d~ → Dump it (no scheduling, just capture)
- Know when to do it? ~C-c o s~ → Schedule it
- Done with task? On the task, press ~t~ until DONE

*** Evening (5 min)
1. ~C-c o i~ → Review inbox
2. On each item: ~r~ to refile to tasks.org, or ~s~ to schedule, or ~d~ to delete

** Weekly Review (Sunday, 15 min)

1. ~C-c w~ → Starts weekly review
2. Process inbox completely
3. ~C-c o w~ → See the week ahead
4. ~C-c o u~ → Check upcoming deadlines

** Inside Agenda View

| Key   | Action                |
|-------+-----------------------|
| ~t~   | Cycle TODO state      |
| ~T~   | Schedule for TODAY    |
| ~M~   | Schedule for TOMORROW |
| ~s~   | Schedule (pick date)  |
| ~d~   | Set deadline          |
| ~r~   | Refresh view          |
| ~RET~ | Go to task            |
| ~q~   | Quit agenda           |

*** Navigation (Evil)

| Key   | Action              |
|-------+---------------------|
| ~j/k~ | Move down/up        |
| ~f/b~ | Forward/back by day |
| ~.~   | Go to today         |

** File Structure

#+begin_example
~/org/agendas/
├── inbox.org      ← Dump everything here first
├── tasks.org      ← Active work (scheduled/deadlined)
├── projects.org   ← Multi-step projects
└── someday.org    ← "Maybe later" ideas
#+end_example

** Quick Capture Keys

| Key | What                  | Where      |
|-----+-----------------------+------------|
| ~d~ | Quick dump (no date)  | inbox.org  |
| ~t~ | Today's task          | tasks.org  |
| ~s~ | Scheduled task        | tasks.org  |
| ~D~ | Task with deadline    | tasks.org  |

** The One Rule

*Capture fast, schedule later.*

Don't think about when during capture. Just dump (~C-c o d~).
Then once a day, process inbox and schedule.
